⚙️ Connect Your Google Sheet

This dashboard reads and writes directly to Google Sheets via Google Apps Script. Complete these steps once — takes about 5 minutes.

  1. Go to script.google.com and click New project
  2. Open the AIS_GoogleAppsScript.gs file and paste its entire contents, replacing any existing code
  3. Click Deploy → New deployment. Set Type: Web app, Execute as: Me, Access: Anyone
  4. Click Deploy, authorize the permissions, then copy the Web App URL
